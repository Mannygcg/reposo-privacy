# Reposo privacy policy

Public privacy policy for Reposo, an app and notification blocker with a fishing game for Android,
served with GitHub Pages at https://mannygcg.github.io/reposo-privacy/.

`store/` holds the Google Play listing assets: `icon-512.png`, `feature-graphic.png` (1024×500),
`screenshots/` (1080×1920 framed phone screenshots, captured Oct 25, 2026) and `listing.md` (store
text in English and Spanish).
